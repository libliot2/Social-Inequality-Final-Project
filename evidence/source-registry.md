# Source Registry

[返回项目首页](../README.md) · [证据库](evidence-master.md)

一个 Source ID 对应一份可辨识的作品或一套行政/数据库产品。出版版本、权威摘要和本地副本随同一条登记。单独发布但复述同一研究的新闻稿保留出处，并注明共同证据。引用线索以 DOI 或规范化 URL 去重，仍待辨识的不同 URL 可能是同一作品的载体。固定版本后再合并，保留旧 ID 为重定向。

`unknown` 代表未确认；`—` 代表不适用、无本地副本或当前无已登记证据。公开可读与许可状态分别记录。Crossref 元数据用于校对部分题名、作者与年份，不能替代原文核查。
