## 本轮去重与核查

- 统一 E01–E48，避免把多份报告引用的相同结果作多项证据。成员汇编中重复或扩展的 Du 工资、Shen OR、Liu BCSPS、Netz 收益、Peng 笼统学历评价分别归入 E21、E20、E18、E35、E37。E35 补图表和模型，不加第二条相同回报发现。
- 成员汇编带来的实质新增对应 E49–E54、E58。Shen Table 2 和 R13 有部分重复，统一为 E51 一条。E55 是从 R14 附录核定了原表的既有线索。E56、E57、E59 是源材料补出的比较或待核条目。E60–E63 补两篇原始中文教育选择研究和两篇 CIEFR-HS 家庭教育支出研究的定位。
- 15 条新增证据中 12 条有明确原文定位，1 条只完成部分核对，2 条尚未达到核查门槛。新增条目不继承原报告自行给出的标签。书目 DOI/规范 URL 去重后，Source Registry 登记可辨识作品和待辨识链接两类，辅助材料另有 SR ID。
- 本轮使用本地 PDF、HTML、出版商与作者全文、官方统计入口及 Crossref 元数据。Crossref 个别 DOI 未返回有效记录，按原文或原报告登记并保留 unknown。E38–E40 的本轮正文请求返回 403。未到达的全文和未复核的外部链接在源记录、案例库或待核清单中标明。

## 公开范围与权利复核

GitHub 仓库在整合时为公开。对现有文件检查了归档许可文字、课件范围、报道中的个人资料、HTML 正文和明显密钥/私有数据风险。本次无删除或转私有操作。建议小组在后续独立变更中处理下列问题。

| 资料 | 审计观察 | 建议 |
| --- | --- | --- |
| 课程要求 PDF | 可见授课材料和作者元数据，文件未附对外再分发许可 | 由课程团队确认可否公开。未确认前可用经允许的课程链接或精简摘要，原件保存在获准访问的位置 |
| 4 个机构/出版摘要、2 个项目页、3 个校方人物报道的 HTML | 页面公开可读，快照包含原网站全文、脚本或链接。校刊明确有版权，正文可能含公开职业联系方式。通用脚本中的 password 字段为表单/遥测配置，未据此认定存在真实口令 | 检查逐站复制授权。对外优先使用书目、原 URL、简短转述和文本定位。校方人物仅保留已经公开且与研究必要的背景，不复制照片或额外联系信息 |
| Erasmus 报告、新闻稿和出版页 | 欧委会一般重用政策含署名与第三方权利限制，个别图片或材料需要单独检查 | 逐对象核权利声明，保留官方链接与署名。如授权不清，公开库改用定位链接，授权副本另存。[欧委会重用声明](https://commission.europa.eu/legal-notice_en) |
| Lan 全文、Netz 全文 | Lan 出版稿与机构封面标 CC BY-NC-ND。Netz 出版稿标 CC BY 4.0 | Lan 仅在符合署名、非商业、无改编条件时公开分发原件，勿发布修改版。Netz 保留署名、许可与版本。两项均直接引用原件 DOI |
| 非公开人物和组员信息 | 目前案例来自公开机构报道或论文中的研究化名。Git 公开历史包含提交者的署名与邮箱。原始访谈或微观调查文件未出现在库中 | 将非公开访谈、录音、可识别细节和受限微观数据放在经授权空间。未来贡献需要公开匿名方式时可用 GitHub noreply 邮箱。已有历史的任何变更需组员确认 |
| 外部文章全文 | Du 等作者版本可读，部分出版商 PDF 可查。在网页可读与仓库再分发之间存在许可区别 | 本轮仅增加链接和研究摘要。组内逐项确认许可后再归档全文 |

发现重复作品时优先补同一 Source ID 的版本和定位。原归档迁移或权限调整由组员审查，确保贡献记录和可追溯出处有承接位置。
