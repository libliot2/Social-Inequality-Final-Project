# UCUG3801 海外留学、社会不平等与社会流动

HKUST(GZ) UCUG3801 Social Inequality and Social Mobility 的 Final Project 研究库。研究问题是：**海外留学是在促进社会流动，还是在强化阶层优势？家庭投入、国际化教育与就业回报如何关联？**

**当前阶段为 Exploratory Research。** 研究资料已按证据、模块和分析组织。最终 Focus Topic 和 Central Argument 留待小组讨论。课上的最终展示要求应用 1–3 个课程概念到真实案例，详见 [课程要求](course/GroupPresentationInstruction202627Fall.pdf)。

## 当前关键发现

- 家庭出身与考虑、参与和获得 offer 均有关。现有研究的地区、抽样和阶段各异，无法直接估计同一队列每一步的差距。见 [E17–E20](evidence/evidence-master.md#e17)、[E51–E52](evidence/evidence-master.md#e51)。
- 招聘实验中部分海外学历标签产生回访劣势。已就业研究生的工资估计及其异质性属于另一结局。见 [E29–E30](evidence/evidence-master.md#e29)、[E21–E26](evidence/evidence-master.md#e21)。
- 家庭支持既涉及出国融资，也可能延伸到求职、等待与关系动员。奖学金可改变部分学生的入学机会。长期岗位、工资和代际职业变化仍缺直接证据。见 [E37–E40](evidence/evidence-master.md#e37)、[E53](evidence/evidence-master.md#e53)、[C001](evidence/case-bank.md#c001)。
- 区分完整海外学位、短期交换、国外工作、工资与代际阶层位置。欧洲就业证据与中国研究可对照设计和制度。见 [跨研究矩阵](analysis/cross-study-matrix.md)。

## 核查与交接

R14 的 E01–E48 用作统一编号。多个报告引用同一发现仅在贡献字段补记。同一论文的不同结局可分别给 Evidence ID，并用同一 Source ID 标识共同研究。Verified 说明原件支持记录中的表述；因果推断还要看随机化、选择、模型和目标总体。Partially Verified 和 Unverified 的具体缺口随条目保存。优先核对[尚未解决的问题](analysis/evidence-gaps.md)。

Chat 和 Work 可以从 README、研究状态、对应模块和证据条目开始，引用时附编号与定位。Codex 和组员在工作分支先读维护规则和交接状态，再检查是否有人处理同一缺口。新增资料、核查结果或报告通过 PR 提交并保留贡献归属。个人数据和源文件授权见[公开风险审计](analysis/repository-audit.md#公开范围与权利复核)。
